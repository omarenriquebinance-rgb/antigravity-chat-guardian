# Security & Privacy Policy

## 🔒 Privacy Guarantee

**Antigravity Chat Guardian** is built from the ground up with a **Privacy-First, Local-Only** architecture.

- **No Remote Telemetry:** The application contains zero network outbound calls, tracking, analytics, or telemetry.
- **Local Storage:** All backups, logs, and databases are stored strictly on your local filesystem under the `backups/` directory.
- **Git Safety:** The repository includes a comprehensive `.gitignore` preventing accidental commits of personal chats, logs, databases, and environment files.

## Reporting a Vulnerability

If you discover any security vulnerability or issue:
1. Please do **not** open a public issue.
2. Send a report with details to the maintainer or create a private GitHub Security Advisory.
3. Include reproduction steps, environment details, and expected behavior.
